📊 Excel KPI Dashboard

📁 Project Overview

This project is an Excel-based Financial & HR KPI Dashboard designed to visualize key business metrics — including revenue, expenses, satisfaction rates, and hiring trends — in one interactive, executive-ready report.
It demonstrates the power of modern Excel tools such as Pivot Tables, Charts, Conditional Formatting, and Data Modeling for data-driven decision-making.


🎯 Objectives
	•	Track sales, expenses, and profit trends over time.
	•	Visualize departmental performance (Finance, Operations, Strategy, and Commercial).
	•	Monitor HR metrics such as hiring vs. terminations.
	•	Provide a holistic performance snapshot for leadership and stakeholders.


🧠 Key Insights
	•	Identified 33% total expense variance year-over-year.
	•	Visualized performance target achievement at 75%.
	•	Highlighted top-performing business units contributing most to revenue.
	•	Enabled cross-department comparisons through visual KPI breakdowns.
